# Verdeyen Games

The home page for our games: https://verdeyen-k.github.io/games/

Each game lives in its own repo and is published with GitHub Pages under the same address, so this page just links to them:

- Miner Mania: `/minermania/`
- Bees Nest: `/beesnest/`
- Type and Seek: `/typeandseek/`
- Froggy Draw: `/froggydraw/`
- Stacktics: `/stacktics/`
- Universal Dog Capture: `/universal-dog-capture/`
- As Yet Unnamed: `/asyetunnamed/`

To add a game, publish its repo with GitHub Pages, then add a card for it in `index.html`.
